# Daewon Gwak — Academic Homepage

GitHub Pages (Jekyll) site for `https://daewongwak.github.io`.

Upload the contents of this archive into the root of the `daewongwak.github.io` repository.
GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)`.

Edit `_data/about.yml`, `_data/publications.yml`, `_data/patents.yml`, `_data/awards.yml`, and `_data/service.yml` to update content.
Only published paper/code URLs appear in Publications. Pending patent filings are excluded.
